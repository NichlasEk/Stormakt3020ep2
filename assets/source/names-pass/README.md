# De strukna namnen: bildproduktion

Manifesten innehåller kondenserade produktionsbriefar, faktiska referenser, utfallsfiler och SHA-256. De är inte ordagranna avskrifter av verktygsanropen. De fullständiga anropen finns i sessionens verktygshistorik. Bilderna är nya utfall med bevarade originalfiler; runtime använder bara repots assets.

Skala: vuxen ståhöjd 150 världspixlar, motsvarande en vald referens på 1,78 m. Specialistarkens neutralposer mäts vid laddning, och samma skala används genom varje rolls tre poser. Miljöns props har minskats genom bildredigering och granskats i spelkameran. Ett fullt måttsatt 3D-underlag återstår för nästa miljö.
